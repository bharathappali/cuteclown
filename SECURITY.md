# Security Policy

## Supported versions

Security fixes are applied to the latest released versions of published `@cuteclown/*` packages. Until the first release, report issues against the `main` branch.

| Version | Supported |
| ------- | --------- |
| `main` (pre-release) | Yes |
| Published releases | Latest minor of each package once published |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Prefer one of:

1. **GitHub Private Vulnerability Reporting** on this repository (Security → Advisories → Report a vulnerability), if enabled.
2. Email the maintainers via the contact listed on the GitHub organization/profile for this project, with subject `CuteClown security`.

Include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept if available
- Affected package names and versions (or commit SHA)

You should receive an acknowledgement within 7 days. We will coordinate a fix and disclosure timeline with you. Please keep the report private until a fix is released or we agree otherwise.
